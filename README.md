# Elegance Boutique – Responsive Clothing Boutique Website

Elegance Boutique is a **demo-based clothing boutique website** developed as an academic web development project. The project demonstrates a dynamic, responsive business website built using **PHP, MySQL, HTML, CSS, and JavaScript**.

The website provides a customer-facing interface for browsing clothing products, viewing product details, exploring categories and gallery content, submitting inquiries, and placing product orders. It also includes a secure admin panel for managing website content and customer orders.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Home, About, Products, Gallery, and Contact pages
* Dynamic product catalog connected to MySQL
* Product categories and product details
* Product image upload functionality
* Gallery management
* Team member management
* Customer contact form
* Product ordering system
* Admin login and session-based authentication
* Admin dashboard
* CRUD operations for website content
* Order and order-item management
* MySQL database integration
* PHP-based backend
* Responsive admin panel
* Form validation and database security practices

## Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive layouts
* **JavaScript** – Client-side functionality
* **PHP** – Backend development and server-side processing
* **MySQL** – Database management
* **XAMPP** – Local development environment
* **GitHub** – Source code management
* **GitHub Copilot** – AI-assisted coding
* **ChatGPT** – AI-assisted development, debugging, UI suggestions, and content assistance

## Admin Panel

The project includes an admin panel that allows authorized administrators to:

* Add, edit, view, and delete products
* Manage product categories
* Manage gallery images
* Manage team members
* View customer orders
* View individual order details
* Manage website content

## Database

MySQL is used to store and manage dynamic website information. The project includes related tables for areas such as:

* Categories
* Products
* Gallery
* Team Members
* Orders
* Order Items

## Project Purpose

This project was created as a **demo/academic implementation** to demonstrate practical knowledge of responsive web development, PHP, MySQL database integration, CRUD operations, authentication, image uploads, and order management.

**Note:** Elegance Boutique is a fictional business created for academic demonstration purposes. The business information, products, and content used in the project are for demonstration only.

## Running the Project Locally

The project can be run locally using **XAMPP** with Apache and MySQL.

1. Clone or download the repository.
2. Place the project folder inside the XAMPP `htdocs` directory.
3. Start **Apache** and **MySQL** from the XAMPP Control Panel.
4. Create the required MySQL database.
5. Import the provided `.sql` database file using phpMyAdmin.
6. Configure the database connection in the project.
7. Open the project through `localhost` in a web browser.
